Load a web game and drive it with persona players. The game and the lab talk over a tiny
      postMessage protocol: the game asks the lab how a given persona would answer an item, and reports
      each player's outcome. A working demo game is loaded below.

    

      

        
Game under test

        

          
          

            
            
          

          
        

        

          
          
        

        
        

          Protocol. The game receives persona-test:init with its players, then for each item it
          posts persona-test:item {playerId, item:{guess,slip,learn}} and the
          lab replies persona-test:response {correct, latencyMs, usedHint}.
          The game posts persona-test:result {playerId, mastery} per player.
          A real game drops in a ~15-line adapter; the demo implements it in full.
